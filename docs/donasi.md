# Program Donasi & Infak

Setiap donasi yang masuk digunakan secara transparan untuk program yang tercantum. Pilih program di bawah, lalu salurkan melalui QRIS atau transfer ke rekening resmi DKM Masjid Al-Birru.

## Salurkan Donasi

<DonasiQRIS />

::: tip Donasi Rutin
Amal yang sedikit tapi konsisten lebih dicintai Allah daripada amal besar yang terputus. Anda juga dapat menjadwalkan donasi rutin bulanan melalui transfer ke rekening DKM.
:::

::: info Konfirmasi & Pertanyaan
Setelah transfer, mohon konfirmasi melalui WhatsApp agar dapat dicatat dan dilaporkan. Untuk pertanyaan terkait program donasi, hubungi sekretariat masjid.
:::
